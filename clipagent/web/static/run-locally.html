clipagent. GitHub

The studio runs
on your machine.

clipagent transcribes, tracks faces and renders video locally, so your footage never leaves your computer. Install it once, then open the studio in your browser.

This site is the public homepage. Video processing needs ffmpeg, Whisper and long-running jobs, which a static host can't run.

Install guide Back to home 
# 1. get the code
git clone https://github.com/nagadattasaikondoju-ship-it/cliping-agent-
cd cliping-agent-

# 2. install (macOS / Linux)
./scripts/install.sh

# 3. add a key to .env (optional)
GEMINI_API_KEY=...

# 4. open the studio
clipagent serve
# → http://localhost:8000/app
